Para correr el programa, hay que crear un folder, dentro de este folder hay que crear dos, uno con el nombre de "bin" y uno con el nombre de "src". Todos los archivos del repositorio se tienen que poner en src. Despues se tiene que hacer click derecho dentro del folder que contiene a "bin" y "src", y se selecciona la opcion para abrir la terminal. dentro de la terminal se corren "javac -d bin src*.java" y despues "java -cp bin Main".
